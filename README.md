The ARD is not an original dataset. It is a derived analysis-ready table generated by integrating multiple ADaM datasets into a single patient-level structure.

The ARD is intended to be an analysis-ready dataset, so ADaM is the most appropriate source. ADaM datasets already contain the derived analysis variables, analysis visits, analysis flags, and analysis values needed for statistical analyses.

SDTM, on the other hand, is designed for data tabulation and regulatory submission. It preserves the collected clinical data but does not usually contain the analysis derivations required to build the ARD efficiently.
